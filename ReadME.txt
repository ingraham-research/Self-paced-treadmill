Ingraham lab's self-paced treadmill code, by Zijie. This code directly interfaces QTM and MATLAB to control the treadmill because we don't use a Speedgoat RT machine. This branch works for MATLAB versions 2023 and before (using tcpip())

This code is based on, and modified from the following paper: S Song, H Choi and SH Collins, Using force data to self-pace an instrumented treadmill and measure self-selected walking speed.
Original code github link: https://github.com/smsong/self-paced-treadmill/tree/JNER2020
